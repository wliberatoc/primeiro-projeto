#Projeto de Landing Page para App fitnes

Página com fundo brnaco e fonte Roboto como principal.
Objetivo é ter uma landing page clean,  brnaca e sofisticada.

## Seção de HEADER:

Logo no canto esquerdo
- A logo é um F em um cículo (feito com CSS)
- o fundo do círculo é VERDE ESCURO

## Seção de HERO SECTION:

A hero deve ter altura de 90vh, dividido em 3 áreas horizontais:

Esquerda:
Apenas a headline, sem ser grande demais, sem destaque (o destaque é o print do app no meio).
"O app perfeito para acompanhar sua vida fitness."

Centro:
Em destaque a imagem images/print_1.png que é um print do app.

Direita:
Uma çista de pontos-chve sobre o app:
- ❤️ Saúde 
- 🏃 Exercícios
- 👥 Amigos

## Seção de FUNCIONALIDADES:

Vão ser usadas as images/print_2.png, images/print_3.png e images/print_4.png que serão exibidas da seguinte forma:
- print / texto
- texto / print  
- print / texto

Ou seja, irá alternar entre o print na esquerda e um texto explicativo na direita, vice-versa.

Descrição breve de  cada print para vc gerar um texto adequado:
- print_2.png = Contagem de calorias
- print_3.png = Exercícios específicos (corrida, musculação, etc)
- print_4.png = Compartilhamento com amigos

## Seção de CTA (call-to-action):
Botão grande de download com um texto abaixo dele destacando:
"Totalmente gratuito"

## Seção de RODAPÉ:
Apenas com o texto "Todos os direito reservados"
