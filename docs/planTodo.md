# Projeto: Página de To-do list simples com HTML, CSS e JS

Este será um projeto de tela única, em que na parte superior teremos um botão de texto para adicionar uma tarefa nova e um botão de envio.

Ao enviar a tarefa, ela será adicionada a uma lista exibida logo abaixo desse campo de texto.

As tarefas serão armazenadas em um array no próprio js, sem uso de nenhuam ferramenta ou sistema interno.

Cada tarefa:
- testo
- boolean confirmando se está feita ou não

Sobre as ações possíveis em cada tarefa:
- Marcardesmarcar ela como concluída, daí o texto fica riscado (via css class "checked").
- Deletar uam tarefa, entãi ela some da lista completamente.
- Adicionar uma tarefa nova através do campo de texto na parte superior da tela, que será sempre adicionada com o boolean de confirmação false.

O projeto será feito utilizando HTML, CSS e JS simples.

No js, trabalhar com EventListeners e nao eventos no HTML diretamente.
No início do js, já selecione em que variáveis todos os elementos que serão manipulados.

Interface gráfica:
- O fundo do projeto será cinza claro já usado na index.
-Tanto o campo quanto a lista ficarão em cards separados, com fndo branco, bosrda arredondada e uam leve serparação enter os cards.

A cor predominante para os botões(como adicionar e deletar) será o verde escuro padrao do projeto.
